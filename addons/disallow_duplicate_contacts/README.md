# Disallow Duplicate Contacts — By Showline Solutions

![Disallow Duplicate Contacts](static/description/icon.svg)

A professional Odoo module that prevents the creation of duplicate contacts using multiple configurable matching rules with license protection.

---

## Features

| Feature | Description |
|---------|-------------|
| 🔍 **6 Detection Rules** | Exact Name, Email, Name+Email, Phone, Name+Phone, Name+Address |
| ⚡ **Real-Time Validation** | Checks on create, write, and quick-create |
| 👁️ **On-Change Preview** | Warns before saving if a duplicate is detected |
| 🔗 **Redirect to Duplicate** | Direct link to view existing contact |
| 🔐 **License Protected** | One-time activation with 12-hour auto-validation |
| 🎨 **Professional UI** | Red-themed branding with clear status indicators |

---

## Installation

1. Copy the `disallow_duplicate_contacts` folder to your Odoo addons directory.
2. Update the Apps list in Odoo.
3. Search for "Disallow Duplicate Contacts" and click **Install**.
4. Go to **Settings → General Settings → Disallow Duplicate Contacts** to activate.

---

## Usage

1. Activate your license key in Settings.
2. Enable your desired detection rules.
3. The module automatically checks for duplicates when creating or editing contacts.
